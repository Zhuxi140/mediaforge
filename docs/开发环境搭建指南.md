# 开发环境搭建指南

## 前置依赖

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| Go | 1.23+（见 `go.mod`） | 后端编译 |
| Node.js | 16+ | 前端构建 |
| npm | 8+ | 前端依赖管理 |
| Wails CLI | v2.12.0+ | 桌面应用框架 |
| FFmpeg | — | 见下方说明 |

---

## 安装步骤

### 1. 安装 Go

从 https://go.dev/dl/ 下载安装 Go 1.23+，验证：

```bash
go version
```

### 2. 安装 Node.js

从 https://nodejs.org/ 下载安装 Node.js 16+，验证：

```bash
node --version
npm --version
```

### 3. 安装 Wails CLI

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

验证：

```bash
wails version
```

### 4. 准备 FFmpeg 二进制文件

该项目将 FFmpeg 嵌入到 `pkg/media/bin/` 中。

- 从 https://www.gyan.dev/ffmpeg/builds/ 下载 **ffmpeg-release-full.7z**
- 解压后找到 `bin/ffmpeg.exe`（和可选的 `bin/ffprobe.exe`）
- 复制到 `pkg/media/bin/ffmpeg.exe`

> **注意**: 仓库已包含 FFmpeg 二进制，首次克隆后检查该文件是否存在。
> 二进制文件较大（~150MB），建议使用 Git LFS 管理。

### 5. 安装前端依赖

```bash
cd frontend
npm install
cd ..
```

---

## 启动开发服务器

```bash
wails dev
```

这会同时启动：
- Go 后端（热重载需手动重启）
- Vite 前端开发服务器（HMR 热更新）
- 桌面窗口自动打开

如果仅需前端开发，可在 `frontend/` 目录下运行：

```bash
npm run dev     # Vite 开发服务器（浏览器中查看）
npm run build   # 类型检查 + 生产构建
```

## 生产构建

```bash
wails build
```

输出文件：`build/bin/mediaforge.exe`

## 常见问题

### Q: `wails dev` 启动报错 "ffmpeg not found"

确保 `pkg/media/bin/ffmpeg.exe` 存在。首次运行会在 `%APPDATA%/MediaForge/engine/` 释放 FFmpeg。

### Q: 前端类型检查报错

```bash
cd frontend
npm run build   # 运行 vue-tsc --noEmit 检查类型
```

### Q: Wails bindings 未更新

如果修改了 `controller/` 层的 Go 方法签名，重新运行 `wails dev` 会重新生成 `frontend/wailsjs/go/` 下的绑定文件。

### Q: 如何添加新的 Go 后端方法？

1. 在 `controller/*_app.go` 中添加带 `context.Context` 的方法
2. 确保方法在 `main.go` 的 `Bind: []interface{}{}` 中注册
3. 重启 `wails dev`
4. 前端从 `wailsjs/go/controller/{AppName}.js` 导入
