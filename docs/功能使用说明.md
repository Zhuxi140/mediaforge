## 1. 通用操作

### 1.1 启动应用

- 运行 `build/bin/mediaforge.exe`
- 首次启动会自动释放 FFmpeg 和 FFprobe 引擎到 `%APPDATA%/MediaForge/engine/`，稍等片刻

### 1.2 导航

顶部标签栏有四个标签，点击切换功能模块：

| 图标 | 名称 |
|------|------|
| ✏️ | 重命名 |
| 🎬 | 影音工厂 |
| 💬 | 字幕处理 |
| 📥 | M3U8 流媒体 |

### 1.3 选择文件

- **对话框**：在每个模块左侧控制面板点击"选择文件"按钮
- **拖拽**：直接将文件拖入右侧数据视图区域

### 1.4 弹窗系统

操作中可能弹出四种类型的弹窗：

| 类型 | 用途 | 示例 |
|------|------|------|
| ℹ️ 信息 | 普通提示 | 操作成功通知 |
| ✅ 成功 | 操作完成 | "成功重命名 5 个文件" |
| ⚠️ 警告 | 需要确认 | 字幕不兼容警告，提供"强行丢弃"选项 |
| ❌ 错误 | 操作失败 | 转码失败原因 |

## 2. 模块一：批量重命名

### 2.1 快速上手

1. 点击顶部标签切换到「重命名」模块
2. 点击左侧面板的「选择文件」按钮，选中要重命名的文件
3. 选择重命名模式：
   - **基础替换**：适合简单的加前缀/后缀/替换字符
   - **智能解析**：适合从混乱的文件名中用正则提取信息重组
4. 右侧表格实时显示预览结果
5. 确认无误后点击「执行重命名」

### 2.2 基础替换模式

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 文件前缀 | 在原文件名前加固定文字 | `2026_` |
| 文件后缀 | 在原文件名后加固定文字（扩展名前） | `_v1` |
| 查找字符 | 要替换掉的旧文字 | `old` |
| 替换字符 | 替换成的新文字 | `new` |

**示例**：文件 `photo.jpg`，前缀 `2026_`，后缀 `_v1`
→ `2026_photo_v1.jpg`

### 2.3 智能解析模式

适合文件名混乱但包含规律信息的场景，如：

```
20230101_张三_大数据1班.pdf
大数据2班_20230102_李四.pdf
王五_20230103_大数据3班.pdf
```

**操作步骤**：

1. 定义提取变量（名称 + 正则）：
   - 变量 `id` → 正则 `202\d{8}` （匹配日期）
   - 变量 `class` → 正则 `大数据.*?[0-9]*班`
   - 变量 `name` → 正则 `\p{Han}{2,4}` （匹配 2-4 个汉字）
2. 设置目标模板：`{class}-{name}_{id}`
3. 选择过滤干扰字符（空格、横线等）
4. 预览结果：

```
20230101_张三_大数据1班.pdf → 大数据1班-张三_20230101.pdf
大数据2班_20230102_李四.pdf → 大数据2班-李四_20230102.pdf
王五_20230103_大数据3班.pdf → 大数据3班-王五_20230103.pdf
```

**注意**：
- 红色行表示变量提取失败（缺失要素）
- 黄色行表示目标文件已存在（同名冲突）
- 执行时自动跳过红色/黄色行

### 2.4 行内编辑

- 对有冲突或格式错误的文件，点击「修正」按钮
- 直接在表格行内修改文件名
- 回车保存，Esc 取消

## 3. 模块二：影音工厂

### 3.1 快速上手

1. 切换到「影音工厂」模块
2. 点击「选择媒体文件」添加视频/音频文件
3. 在左侧配置全局转换参数
4. 可修改每个文件单独的目标格式
5. 点击「一键全部转换」或单个文件的「转换」按钮

### 3.2 配置说明

| 配置项 | 说明 |
|--------|------|
| 媒体类型 | 视频处理或音频提取，切换后目标格式选项同步变化 |
| 目标格式 | 视频可选 mp4/mkv/avi/gif，音频可选 mp3/wav/aac/flac |
| 编码加速引擎 | 默认 CPU 软解，有 NVIDIA/Intel/AMD 显卡可选对应硬件加速 |
| 输出质量 | 极速(Low) / 平衡(Medium) / 高质量(High) / 自定义(Custom) |
| 输出目录 | 留空则输出到原文件相同目录 |

### 3.3 硬件加速

| 选项 | 适用显卡 | 对应编码器 |
|------|---------|-----------|
| CPU 软解 | 任何 | libx264 |
| NVIDIA NVENC | NVIDIA GTX 10 系列+ | h264_nvenc |
| Intel QSV | Intel 核显 | h264_qsv |
| AMD AMF | AMD Radeon 显卡 | h264_amf |
| Apple Mac | Mac 设备 | h264_videotoolbox |

### 3.4 质量参数

| 预设 | 视频 CRF | 音频 VBR | 适用场景 |
|------|---------|---------|---------|
| 极速/普清 | 28 | 5 | 快速预览、在线传输 |
| 平衡（默认） | 23 | 2 | 日常使用，兼顾画质和体积 |
| 高质量 | 18 | 0 | 存档备份，保留最佳画质 |
| 自定义 | 手动输入 | 手动输入 | 精确控制输出质量 |

### 3.5 字幕兼容性处理

当转换 MP4 且源文件包含不兼容的内封字幕时：

1. 弹出警告弹窗：
   > "包含 MP4 不兼容的内封字幕流！强行转换可能导致程序崩溃或丢弃字幕"
2. 用户选择：
   - **强行丢弃**：添加 `-sn` 参数跳过字幕，继续转换
   - **取消**：先去字幕模块提取字幕，再单独转换

### 3.6 元数据查看

每个任务行右侧有「元数据」按钮，点击后在工作区底部显示文件的完整元信息，包括容器格式、文件大小、时长、总比特率、视频流（编码/分辨率/帧率/像素格式）、音频流（编码/采样率/声道/语言）、字幕流（编码/语言）。

### 3.7 任务管理

- **实时进度**：每个任务显示 `处理中: HH:MM:SS.MS`
- **停止**：点击「⏹️ 停止」取消正在处理的任务
- **错误任务**：可通过「清除失败任务」一键移除
- **批量操作**：先添加所有文件，再一键转换

## 4. 模块三：字幕处理

### 4.1 两种模式

- **视频提取**：从 MKV/MP4 等视频文件中提取内封字幕
- **格式互转**：在 srt/ass/vtt 等字幕格式间相互转换

### 4.2 提取模式

#### 操作步骤

1. 切换到「字幕处理」→「视频提取」模式
2. 点击「选择视频」或拖拽视频文件到右侧区域
3. 自动探测字幕流，显示每条字幕的索引、语言、编码
4. 勾选要提取的字幕流（默认全选）
5. 选择输出格式（srt / ass / ssa / vtt / ttml / smi）
6. 点击「一键提取所有勾选」或单个「提取」按钮

#### 格式说明

| 格式 | 特点 | 适用 |
|------|------|------|
| SRT | 最通用，纯文本时间轴 | 播放器兼容性最好 |
| ASS | 支持特效、字体、样式 | 字幕组、特效字幕 |
| SSA | ASS 的前身，兼容 ASS | 旧版软件 |
| VTT | HTML5 标准格式 | 网页视频 |
| TTML | 广电/流媒体标准 | 专业广播 |
| SMI | 微软 SAMI 格式 | Windows Media Player |

#### 特殊字幕格式警告

勾选 MicroDVD 或 VobSub 格式的字幕时弹出预警，因该类字幕缺乏绝对时间戳或包含图形数据，强行提取可能失败。

### 4.3 互转模式

#### 操作步骤

1. 切换到「字幕处理」→「格式互转」模式
2. 点击「选择字幕文件」添加字幕
3. 可修改单个文件的目标格式和输出文件名
4. **必须**配置输出目录或为每个文件指定新文件名
5. 点击「一键全部转换」或单个「转换」按钮

#### 安全校验

- 输出目录与原文件相同目录 + 未指定新文件名 → 拒绝执行
- 防止 FFmpeg 写入自身导致覆盖冲突

### 4.4 支持的字幕格式

输入：srt / ass / ssa / vtt / txt / ttml / smi / sub
输出：srt / ass / vtt / ssa / ttml / smi

## 5. 模块四：M3U8 流媒体

### 5.1 快速上手

1. 点击顶部标签切换到「M3U8 流媒体」模块
2. 输入 M3U8 链接地址
3. 点击「验证有效性」自动分析视频流信息
4. 验证通过后选择保存目录
5. 点击「开始下载」启动下载任务

### 5.2 视频预览

验证成功后，内置播放器自动加载 M3U8 流，支持：

- 播放 / 暂停
- 进度条拖动
- 时间显示
- 音量调节

### 5.3 下载管理

| 操作 | 说明 |
|------|------|
| 开始下载 | 启动 FFmpeg 实时下载任务 |
| 暂停/继续 | 暂停或继续下载进度 |
| 停止 | 立即终止下载任务 |
| 验证后下载 | 验证 + 选择目录 + 下载一条龙 |

### 5.4 任务队列

每个下载任务显示：

| 状态 | 说明 |
|------|------|
| 连接中 | 解析 M3U8 并连接服务器 |
| 下载中 | 实时下载，显示已下载大小/总大小/速度/进度条 |
| 已完成 | 下载完成，文件保存到指定目录 |
| 已停止 | 用户手动停止或网络失败 |

## 6. 常见问题

### Q: 转换速度慢怎么办？

- 在「编码加速引擎」中选择对应的硬件加速（NVIDIA/Intel/AMD）
- 输出质量选择「极速/普清(Low)」可加快速度

### Q: 输出的文件在哪里？

默认输出到原文件所在目录，文件名追加 `_converted` 后缀。
可在控制面板指定自定义输出目录。

### Q: 如何终止正在转换或下载的任务？

点击任务行上的「⏹️ 停止」按钮，或关闭应用（应用关闭时会终止所有任务）。M3U8 下载任务点击「停止」后立即终止 FFmpeg 进程，不会等待当前片段完成。

### Q: 为什么有些字幕提取失败？

- MicroDVD 和 VobSub 格式较特殊，建议使用专业工具
- 确保视频文件包含内封字幕流（非外挂字幕）

### Q: 重命名支持撤销吗？

当前版本不支持撤销。请在预览阶段仔细核对，执行前会显示有效操作数量。

### Q: 为什么执行重命名时报错"文件已存在"？

预览中有标黄的同名冲突行，这些文件会被跳过。如需覆盖，请先手动处理冲突文件。
